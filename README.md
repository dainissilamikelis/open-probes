# open-probes
open web and api probing initiative

This is a bit of a fun side project for me. I am kinda passionate about probing. In one of my workplaces I had to setup some pretty complex KPI/SLA cases for probing and I hope this will ease some issues for other people.

# This is build on top of CDP and NPM
Because why not
1. I have build similar tooling with playwright and I found no real benefit
2. I have build similar tooling with puppeteer and I found some benefit, but I am try-ing to write my own CDP wrapper, and potentially have more access

# This project is my passion project and maybe somebody will use it.
Generally just trying to build some open-source soft and see who might need it
